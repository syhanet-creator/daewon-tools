# daewon-tools — 사진대지 에이전트 (v0.2)

현장 사진을 올리면 EXIF(촬영시각·GPS)를 읽고, AI가 공종·시공단계·설명을 분류해
현장별/공종별로 정리한 뒤 A4 한 장에 4컷씩 들어가는 사진대지 PDF를 만듭니다.
사진과 분류 결과는 Supabase(`khnlu-accounting` 프로젝트)에 저장됩니다.

## 구성
- `index.html` : 모바일 PWA (오프라인 우선: 폰에 먼저 저장 → 연결되면 서버로 업로드)
- `api/classify.js` : Claude 비전으로 공종·단계·설명 분류
- `api/data.js` : Supabase 입출력 (서명 업로드 URL, 목록, 저장, 삭제). 브라우저는 Supabase에 직접 접근하지 않음
- `supabase/migrations/` : 테이블 `pl_sites`, `pl_photos`, 비공개 버킷 `pl-photos` (이미 적용됨)

## AI 토큰 절감 구조
1. **2단계 분류**: 모든 사진을 먼저 Haiku 5.5가 800px로 봅니다(도구 호출 강제 → 추론 토큰 없음). 신뢰도가 낮거나 '기타'로 분류하거나 확인 사유를 단 사진만 Sonnet 5.5가 1024px로 다시 봅니다(추론 최소화: `between_tools` + effort `low`).
2. **프롬프트 캐시**: 공종 판별 기준(고정 지침)을 캐시하여 반복 호출 시 입력 단가의 일부만 냅니다. 캐시 최소 길이는 두 모델 모두 512토큰입니다.
3. **초소형 출력**: 응답은 짧은 키(t,s,c,d,n,r)와 한 줄 캡션만 받습니다.
4. **무료 힌트**: 같은 현장에서 45분 이내 직전 사진의 공종을 힌트로 함께 보냅니다.
5. **재호출 방지**: [다시 분석]은 실패한 사진만 다시 보냅니다. 이미 정밀 분석까지 거친 사진은 카드에서 직접 고칩니다.
6. 설정창에서 누적 분석 장수, 정밀 재분석 비율, 입력/출력/캐시 토큰을 확인할 수 있습니다.

## 사용법
- [촬영]: 카메라로 바로 촬영. EXIF에 위치가 없으면 촬영 순간 기기 위치 사용.
- [갤러리/파일에서 추가]: 여러 장 선택. 위치는 EXIF에 있을 때만 사용.
- GPS 200m 이내는 같은 현장으로 묶이고, 위치 없는 사진은 6시간 이내 직전 사진의 현장에 붙습니다.
- 카드에서 공종·단계·설명 수정, "확인 필요"는 AI 신뢰도가 낮은 사진.
- [사진대지 PDF 만들기] → 현장/기간 선택 → 인쇄 창에서 "PDF로 저장".
- 출력물 머리글·꼬리말에 (주)대원산업건설 로고·상호·업종·주소·연락처가 자동 인쇄됩니다 (`BRAND` 상수, 로고는 `logo.png`). 설정의 회사명을 입력하면 상호만 바뀝니다.

## 알아둘 점
- 안드로이드 Chrome 사진 선택기는 GPS를 지우는 경우가 있어, 위치가 중요하면 [촬영]을 쓰세요.
- 증빙 서류이므로 AI 분류는 초안입니다. 출력 전에 "확인 필요"를 점검하세요.
- 목록은 한 번에 전체를 불러옵니다. 사진이 수천 장 쌓이면 현장·기간별 조회로 바꿔야 합니다.

## 로그인·보안 (AI 토큰 무단 사용 방지)
1. 처음 접속: 임시 비밀번호(`APP_PASSCODE`) 입력 → 즉시 본인 비밀번호(8자 이상)로 변경.
2. 변경 후 이 기기 패턴 등록(선택). 패턴은 로그인 토큰을 암호화해 **이 기기 브라우저에만** 보관하므로 다른 기기에서는 쓸 수 없고, 5회 틀리면 패턴이 삭제됩니다.
3. 서버(`/api/data`, `/api/classify`)는 로그인 토큰이 없으면 AI 호출 전에 거부합니다. 비밀번호 변경 시 다른 기기의 기존 로그인은 모두 해제됩니다.
4. 비밀번호 5회 오입력 시 10분 잠금. 비밀번호는 scrypt 해시로 Supabase `pl_auth`에 저장(서버 전용).
5. 비밀번호를 잊으면 Supabase에서 `pl_auth` 행을 삭제하면 임시 비밀번호 상태로 초기화됩니다.

## 사진대지 보관함
- PDF를 만들 때마다 기록(제목·현장·기간·사진 순서)이 Supabase `pl_ledgers`에 저장됩니다. 오프라인이면 폰에 먼저 저장했다가 연결되면 올립니다.
- 상단 폴더 아이콘 → 보관함에서 [다시 출력]. 현재 저장된 사진·공종 기준으로 다시 만들며, 삭제된 사진은 제외됩니다. PDF 파일 자체는 저장하지 않습니다.

## 저장 방식 (서버 5분 주기)
- 모든 조작(분류 수정·메모·현장명 등)은 먼저 폰(IndexedDB)에 저장되고, 서버로는 **5분에 한 번** 자동 저장됩니다. 그 사이에는 "저장 대기 N"으로만 표시됩니다.
- 하단 [지금 저장] 버튼으로 즉시 저장할 수 있습니다.
- 서버와 내용이 같으면 화면을 다시 그리지 않아, 저장 중에도 스크롤·입력이 유지됩니다.
